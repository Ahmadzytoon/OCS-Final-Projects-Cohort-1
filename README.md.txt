# Codelaren

## Project Description
Codelaren is an educational website for learning programming. It displays various courses and allows users to access video lessons. The platform also includes a section for tracking student progress in each course.

## Features
- Upload and watch videos for each course
- Student progress tracking per course
- Interactive and user-friendly interface

## Technologies & Tools Used
- HTML
- CSS
- JavaScript
- PHP (Laravel)
