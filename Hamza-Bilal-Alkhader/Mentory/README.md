# Mentory

## Project Description

Mentory is a web platform designed to help Jordanian Tawjihi (General Secondary Education) students find the right teachers with confidence.
The platform focuses on trust and transparency by allowing ratings and reviews only after a real request is completed.
Teacher profiles are reviewed and approved by an admin before appearing to students.

## Features

- Browse approved teacher profiles
- Filter teachers by subject and academic field
- Send learning requests to teachers
- Rate and review teachers only after request completion
- Featured top-rated teachers section
- Role-based access (Student, Teacher, Admin)
- Admin dashboard for managing teachers, students, subjects, and reviews
