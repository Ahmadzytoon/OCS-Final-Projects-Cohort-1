# Project Name
Salon Management System

## Project Description
A full-stack web application developed as a final project for Orange Coding School.
The system manages multiple salons, where each salon is owned by a salon owner.
Users can browse salons, use services, and earn coins based on their activities.

## Features
- User registration and authentication
- Salon owner accounts
- Multiple salons management
- Services booking system
- Coins reward system for users
- Admin dashboard
- Responsive user interface

## Technologies & Tools Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Git & GitHub
