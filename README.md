# CodeQuest

## Project Description

CodeQuest is an educational web platform designed to help students learn programming through structured, text-based courses. The platform allows users to browse courses, read learning materials organized into modules and topics, and practice their knowledge through questions. The goal of CodeQuest is to provide a simple, focused, and accessible learning experience without relying on video content.

## Features

- User authentication
- Browse free and paid programming courses
- Instructors can add new courses using a predefined structured format
- Course structure with modules and text-based topics
- Practice questions included within topics to enhance learning
- Student progress tracking and engagement features
