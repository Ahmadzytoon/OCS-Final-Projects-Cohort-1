# Cleanova

## Project Description

Cleanova is a web-based cleaning services marketplace that connects customers who need cleaning services with independent service providers.  
The platform allows customers to browse cleaners, filter them based on location, service type, price, and ratings, then book services easily.  
Service providers can manage their profiles, services, availability, and bookings, while admins oversee the platform to ensure quality and control.

The goal of Cleanova is to simplify the process of finding reliable cleaning services through a clean, user-friendly, and well-structured system.

## Features

- User authentication with different roles (Customer, Service Provider, Admin)
- Browse and filter service providers by ZIP code, service type, price, and ratings
- Booking system with time slots and booking status management
- Service provider dashboard to manage services, availability, and bookings
- Review and rating system for service providers
- Admin panel for managing users, services, and platform data
