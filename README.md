# Legal Q&A (Ask Lawyer)
## Project Description
A comprehensive platform connecting users with verified legal professionals. Users can ask questions, browse advice, and read legal articles, while lawyers can manage their profiles and provide expert answers in a structured, professional environment.
## Features
- **Public Q&A Feed**: Interactive legal question threads with category filtering and real-time search.
- **Verified Lawyer Profiles**: Advanced verification system for lawyers including CV uploads and admin approval workflows.
- **Admin Dashboard**: Centralized control panel for analytics, user management, and verification requests.
- **Dynamic Categorization**: Unified category system across questions, articles, and lawyer specializations.
- **Premium Dark UI**: Professional aesthetic featuring glassmorphism effects, responsive design, and smooth animations.
## Technologies & Tools Used
- HTML5 / CSS3 (Custom Dark Theme)
- JavaScript (Vanilla + Chart.js + SweetAlert2)
- Laravel Framework (PHP)
- Livewire (Full-stack dynamic interfaces)
- MySQL Database
- GitHub
